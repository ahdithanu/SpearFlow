# Spear Flow 3D Direction

The homepage now uses a procedural real time Three.js object called the Spear Core.

## Current implementation

The Spear Core is assembled in browser from an elongated metallic icosahedron, internal blades, orbital rings, particle signals, and a surrounding beam path. The scene uses physically based materials, realtime lights, pointer response, scroll state, adaptive pixel ratio, and reduced motion support.

## Visual meaning

Capture: particles represent raw demand entering from calls, forms, advertising, referrals, and CRM activity.

Understand: orbital movement represents signals being structured and qualified.

Act: the central directional form represents coordinated workflow execution.

Learn: recurring orbital motion represents outcome data feeding back into the system.

## Production quality roadmap

1. Replace the procedural central geometry with a bespoke Blender model while preserving the runtime animation system.
2. Export the production asset as an optimized GLB with compressed geometry and baked detail.
3. Add authored animation clips for dormant, capture, process, act, and scale states.
4. Add scroll state transitions between those animation clips.
5. Add branded shaders for signal flow and internal illumination.
6. Produce a lightweight mobile model and a prerendered fallback for low power devices.
7. Add performance budgets for model weight, texture weight, frame time, and first contentful paint.

## Design rule

3D should communicate the movement from signal to intelligence to action to revenue. Decorative motion should be removed rather than added.
